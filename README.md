# BLACK HEART 🖤

## تشغيل المشروع على Replit

1. استورد هذا المستودع من GitHub إلى Replit.
2. افتح Secrets في Replit وأضف القيم التالية كما هي من مشروعك السابق:
   - `API_ID`
   - `API_HASH`
   - `STRING_SESSION`
   - `GROQ_API_KEY` (اختياري؛ يلزم لتفعيل ردود الذكاء الاصطناعي عبر Groq)
3. اضغط Run. إعداد `.replit` يشغّل `python main.py` تلقائياً، وملف `requirements.txt` يحدد المكتبات المطلوبة.

**مهم:** لا تضع مفاتيحك أو جلسة Telegram داخل ملفات GitHub أو ترسلها في المحادثة. يجب إدخالها في Secrets داخل Replit. لا يمكن تشغيل اتصال Telegram دون `API_ID` و`API_HASH` و`STRING_SESSION`.
